# 📚 TP Terraform

Ce dépôt contient une série de travaux pratiques pour apprendre Terraform.

## 🚀 Accès

Le site est publié via GitHub Pages.

## 📁 Structure

- `/tp` : les différents TP
- `_layouts` : templates HTML
- `assets` : styles

## ✍️ Ajouter un TP

1. Créer un fichier dans `/tp`
2. Ajouter un front matter :

```yaml
